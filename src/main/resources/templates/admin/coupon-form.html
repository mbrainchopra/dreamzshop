Coupon Checklist
Code: Keep it short, memorable, and easy to type.
Discount: Match the value to the selected percentage or fixed type.
Limits: Use sensible usage and customer restrictions.
Validity: Always verify the start and end date before activation.
Admin Tip

Clear coupon codes and realistic limits make promotions easier to manage and reduce accidental over-discounting.
